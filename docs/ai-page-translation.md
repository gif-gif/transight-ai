# AI 网页原位翻译（第一版）

## 使用

1. 在设置中配置兼容 Chat Completions 的服务，选择至少一个模型并同意发送内容。支持原有的加密密钥及免认证本地服务。
2. 重新构建并加载 `dist/`，刷新已打开的网页。
3. 在 popup、划词浮窗或右键翻译浮窗选择目标语言，点击 **AI 网页翻译** 图标。Simple 和 Full 均支持。原来的 Google 整页翻译仍打开新标签页，两者互不替代。
4. 页面右上角显示确认栏：模型列表中的**第一个模型**、目标语言、服务商及隐私/费用说明。点击「同意并开始」才发送页面文字。密钥锁定时可直接在栏内解锁，再点击开始。
5. 状态栏可收起、停止、查看原文/译文、恢复原文并结束。关闭栏会停止翻译并恢复原文。切换原文/译文使用本页内存，不重新调用模型。
6. 修改目标语言后再次打开 AI 网页翻译，会停止旧任务并恢复原文；重新确认后使用新语言翻译。

## 范围与边界

- 当前顶层 HTTP/HTTPS 网页中已渲染的普通文字，包括标题、段落、列表、表格、链接和非编辑按钮。优先翻译视口内的文字，再处理其余内容。
- 保留原来的元素、属性、事件监听和链接，仅修改文本节点。译文的长度会影响换行和页面高度，不保证视觉尺寸完全不变。
- 跳过表单值、可编辑区域、代码、隐藏元素、`translate="no"`、`.notranslate`、ARIA 实时区域和插件 UI。
- 不支持图片文字、Canvas、PDF、iframe 内部文字及 Shadow DOM 内部文字；超大或复杂文字块可能保留原文。
- 新插入或变为可见的文字在本次会话中继续翻译；频繁改动的文本会跳过。地址发生变化后自动停止，需用户再次确认，不自动翻译下一页。相同地址下的网站内容更新属于本页动态内容。
- 网站自身脚本可能重新渲染文字；无法承诺所有框架和特殊排版完全兼容。复杂内嵌链接的语序依赖模型质量；结构校验不能验证翻译的语义准确性。
- 首版使用专用的结构化提示词，继承表达风格，不应用设置中要求纯文字输出的自定义翻译提示词。

## 请求、恢复与费用

- 每批最多 6,000 个 UTF-16 字符、80 个文本片段、24 个语义块；JSON 请求正文另受 12,000 字符限制。最多两个并发批次；单批 20 秒超时。
- 每轮最多发送 60,000 字符 / 100 个请求。达到上限后停止，用户可以确认继续。计数包含失败请求；继续或重新开始会开启新一轮额度，**不是费用的硬上限**。
- 错误批次保留原文。格式错误不影响其他批次，可手动重试未完成文字；认证、网络、配置变化等错误会停止继续发送。
- 停止会取消当前任务并保留已完成译文，无法撤回已到达服务商的文字或费用。
- 对每个响应校验片段 ID 的完整性、唯一性和输出类型。模型输出永远作为文字写入，绝不作为 HTML 执行。
- 写回前验证页面地址、任务代次、节点是否仍在原处，以及文字是否已被网站更改；恢复时只修改仍匹配本插件写入值的节点，不覆盖后续的网站更新。
- 原文和译文只保存在当前页面内存。`chrome.storage.session` 仅保存临时授权、模型/端点、目标语言、计数和时间，不保存网页正文；标签关闭、会话过期或浏览器关闭后清理。
- 调度在页面中执行，后台只处理短批次。后台重启后可使用 session 中的授权继续；若请求通道中断，则保留成功结果，提示用户重新开始，不无限自动重试。
- 登录网页的普通文字仍可能包含敏感信息，排除表单并不等于排除所有隐私数据。仅手动启动，不上传整页 HTML、Cookie 或页面 URL。

## 测试与发布

```sh
npm test
npm run check
npm run test:ai-page-translation
npm run build
```

浏览器测试需要可用的 Playwright 和 Chromium；可通过 `PLAYWRIGHT_MODULE` / `CHROMIUM_EXECUTABLE` 指定位置。测试使用隔离的浏览器配置与本地模拟服务，不使用真实 API Key，也不调用外部模型。

第一版验证覆盖：确认前不发送内容、单模型、目标语言、保留链接和监听器、敏感区域排除、动态内容、原文切换、恢复冲突、停止和导航后的旧响应、格式异常以及各界面入口。真实模型译文质量和大型第三方站点兼容性仍需实际体验。

本功能已纳入当前商店安装包，五种语言的商店说明、截图及隐私/测试说明同步更新。浏览器测试使用本地模拟服务；真实模型质量与第三方站点兼容性仍需实际验证。
