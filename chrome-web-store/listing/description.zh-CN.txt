译见 AI（Transight AI）——让理解，少一点距离。

使用你自己的 AI 服务和模型，在阅读时随手翻译。支持工具栏输入、网页划词和右键翻译，无需离开当前页面，即可阅读并对照多个模型的译文。

你的服务，你的模型
• 配置兼容 Chat Completions API 的服务地址、API Key 和模型 ID。
• 服务商支持时可拉取模型列表，也可手动填写模型 ID。
• 最多同时选择 5 个模型，分别展示独立译文卡片。
• 每个结果可单独复制，失败后可单独重试。

不中断阅读的翻译体验
• 支持手动输入、粘贴文本和选中文字翻译。
• 划词与右键翻译复用同一个页面浮窗。
• 可固定本次浮窗，通过顶部区域拖动位置。
• 1–2 个模型时高度随内容自适应；3 个及以上模型时显示前两张结果卡片，其余滚动查看，小屏幕下以可用空间为限。
• 提供自然流畅、忠于原文和专业精准三种翻译风格。

无需离开当前界面即可解锁
• 通过本地密码保护已保存的 API Key。
• 在工具栏弹出窗口或页面浮窗中直接输入密码；紧凑表单解锁后继续等待中的翻译。
• 可在设置中立即锁定或删除已保存的 Key。忘记密码无法找回，需删除后重新填写 Key 并设置密码。

语言支持
• 目标语言支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、俄语和葡萄牙语。
• 界面支持简体中文、繁体中文与英文，默认跟随浏览器语言，未匹配到时使用英文，也可手动切换。

如何使用
1. 打开设置，填写兼容 AI 服务的 API 地址，以及服务所需的 API Key。
2. 拉取模型列表或手动填写模型 ID，选择希望使用的模型。
3. 保存 API Key 时，设置并确认至少 6 个字符的本地解锁密码。阅读数据发送提示，保存设置并测试连接。
4. 在普通网页中选中文字后点击翻译图标，或使用右键翻译；也可以从工具栏弹出窗口粘贴文本翻译。

使用前请了解
插件不附带 AI 订阅、API Key 或翻译额度，需要自行准备兼容的 AI 服务。服务商可能收取费用；每个选中的模型会分别发送一次请求。也支持不需要认证的本地服务。能否拉取模型列表取决于服务商。

待翻译文本会发送到你配置的 AI 接口。已打开的翻译界面中切换目标语言可能重新发送翻译请求；测试连接会发送短测试请求，拉取模型列表也会访问已配置的服务。API Key 使用解锁密码通过 AES-256-GCM 加密保存在本地；重启浏览器或重载、更新扩展后需重新解锁。密码不保存，也不发送给 AI 服务；解锁后的 Key 仅在会话内存中使用，可在设置中锁定或删除。设置不通过 Chrome 同步。插件不包含统计跟踪，不保存持久翻译历史，也不会自动扫描并上传整篇网页。

所有网站访问权限用于在普通 HTTP/HTTPS 网页提供划词翻译，并访问你配置的 AI 接口。Chrome 内部页面、Chrome Web Store 等受保护页面可能限制页面浮窗功能。AI 译文可能不准确，请自行核实重要内容；提交文本适用所选服务商的数据处理政策。
