译见 AI — 让理解，少一点距离。

使用自己的 AI 服务翻译文字与粘贴图片。可从工具栏打开、点击网页选中文字尾部的翻译图标，或使用右键翻译。

精简与完整，两种模式
• 默认 Full Translate：最多选择 5 个模型并行翻译，独立结果卡片，逐卡复制或失败重试。
• 设置中启用 Simple Translate，或点击浮窗顶部布局图标切换。精简模式只使用模型列表第一项，显示可编辑原文、译文、原文/目标语言选择，不显示翻译按钮。
• 精简模式切换语言或停止输入约 0.6 秒后自动翻译，仍保留复制和本地语音播报。
• 图标支持双向切换，模式即时保存。工具栏 popup 始终保留完整布局。

不中断阅读
• 选中文字后，选区尾部附近出现小图标，约 2.5 秒自动消失；仅选择不上传，点击后才打开翻译。
• 可固定本次浮窗并拖动顶部。1–2 个模型自适应高度，3 个以上优先显示两个，其余滚动查看，受可用屏幕空间限制。
• 源语言可自动检测或手动选择，目标语言在 popup、浮窗、设置间记忆与同步。
• 完整模式支持取消翻译；每个失败模型可独立重试。认证错误中的设置链接可直接打开设置页。
• 点击扬声器朗读，再次点击停止，不自动播放。只使用本地语音，支持情况依赖系统安装的语音。

图片与个性化
• 在 popup 或完整模式原文框粘贴剪贴板图片，最多 5 张。缩略图左上方单行显示，可横向滚动，文字在图片下方输入，图片可单独删除。
• 需要模型支持图片输入。粘贴与预览本身不上传图片。popup 已移除截图入口，请使用系统截图工具复制图片后粘贴。
• 设置可启用/禁用划词图标；关闭后工具栏和主动右键翻译仍可使用。
• 可自定义系统提示词、恢复默认，支持原文、源/目标语言、可用网页标题/description 摘要和翻译风格变量。不抓取整页或额外调用 AI 生成摘要。

开始使用
1. 填写兼容 Chat Completions 的 Base URL，服务需要时填写 API Key。
2. 拉取模型列表或手动输入 ID，最多选择 5 个模型。
3. 保存 Key 时设置并确认至少 6 个字符的本地解锁密码，阅读数据发送提示，保存并测试连接。
4. 在工具栏或普通 HTTP/HTTPS 网页翻译。需要时可直接在 popup/浮窗解锁，继续等待中的翻译。

界面支持简体中文、繁體中文、English、日本語、한국어；默认跟随浏览器，不匹配时英文兜底。显示语言在 popup 或设置页切换，浮窗跟随偏好、不再单独显示语言按钮。翻译目标支持简繁中文、英、日、韩、法、德、西、俄、葡共十种语言。

隐私与限制
不附赠 AI 订阅、Key 或额度。每个模型分别请求，服务商可能收费。翻译时向你配置的服务发送原文、图片及适用的提示词/网页元数据；精简模式编辑、切换语言/模式、重试可能发起新请求。模型列表请求可能发送 Key，连接测试发送示例文字。取消不能撤回服务端已收到的数据。

Key 以 AES-256-GCM 和密码派生密钥在本地加密；解锁后仅在受限 session storage 暂存。重启浏览器、重载或更新扩展后需重新解锁。密码不保存、不发给 AI。没有 Chrome 同步、内置分析统计、持久翻译历史或音频保存。图片仅存在内存，播报仅使用标记为本地的语音。第三方服务仍适用其数据政策。

Chrome 内部页、Chrome Web Store 等受保护页面可能限制浮窗功能。模型列表和图片能力依赖提供方。AI 翻译可能出错，请核对重要信息。
