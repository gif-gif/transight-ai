Transight AI — 언어를 넘어, 의미를 더 가까이.

직접 선택한 AI 서비스와 모델로 읽고 있는 글을 번역하세요. 도구 모음에서 열거나, 웹페이지의 글을 선택한 뒤 번역 아이콘을 클릭하거나, 우클릭 메뉴를 이용할 수 있습니다. 페이지를 떠나지 않고 번역문을 읽고 비교하세요.

모델 선택은 내 뜻대로
• API 기본 URL, API 키, 모델 ID를 설정하여 Chat Completions 호환 서비스에 연결합니다.
• 지원하는 서비스에서는 모델 목록을 가져올 수 있으며, ID를 직접 입력해도 됩니다.
• 최대 5개 모델을 선택하고 독립적인 결과 카드에서 번역을 비교합니다.
• 번역문을 개별 복사하고 실패한 모델만 다시 시도할 수 있습니다.

읽기의 흐름을 유지하세요
• 입력하거나 붙여 넣거나 선택한 텍스트를 번역합니다.
• 선택 번역과 우클릭 번역은 같은 페이지 내 패널을 사용합니다.
• 현재 패널을 고정하고 상단을 드래그해 위치를 바꿀 수 있습니다.
• 모델이 1~2개면 내용에 맞게 높이를 조절합니다. 그보다 많으면 두 결과를 표시하고 나머지는 스크롤로 확인합니다. 사용 가능한 화면 공간에 따라 제한됩니다.
• 자연스러운 번역, 원문에 충실한 번역, 전문적인 번역 스타일을 선택하세요.

페이지를 떠나지 않고 잠금 해제
• 저장된 API 키를 로컬 비밀번호로 보호합니다.
• 도구 모음 팝업이나 페이지 내 패널의 간결한 비밀번호 양식에서 바로 잠금을 해제합니다. 대기 중인 번역은 해제 후 이어집니다.
• 설정에서 즉시 잠그거나 저장된 키를 삭제할 수 있습니다. 잊어버린 비밀번호는 복구할 수 없으며, 키를 삭제하고 다시 입력해야 합니다.

지원 언어
• 번역 대상: 중국어 간체·번체, 영어, 일본어, 한국어, 프랑스어, 독일어, 스페인어, 러시아어, 포르투갈어.
• UI: 중국어 간체·번체, 영어, 일본어, 한국어. 브라우저 언어를 따르며 지원하지 않는 언어는 영어로 표시합니다. 수동 변경도 가능합니다.

시작하기
1. 설정에서 호환되는 AI 서비스의 기본 URL과 필요한 경우 API 키를 입력합니다.
2. 모델 목록을 가져오거나 ID를 입력한 다음 사용할 모델을 선택합니다.
3. API 키를 저장할 때 6자 이상의 로컬 잠금 해제 비밀번호를 설정하고 확인합니다. 데이터 전송 안내를 확인한 뒤 설정을 저장하고 연결을 테스트합니다.
4. 일반 웹페이지에서 글을 선택해 번역 아이콘을 클릭하거나, 우클릭 번역을 사용하거나, 도구 모음 팝업에 텍스트를 붙여 넣습니다.

중요 안내
Transight AI에는 AI 구독, API 키, 번역 크레딧이 포함되지 않습니다. 호환되는 AI 서비스를 이용할 수 있어야 합니다. 제공업체 요금이 발생할 수 있으며 선택한 모델마다 별도 요청을 전송합니다. 인증이 필요 없는 로컬 서비스도 지원합니다. 모델 목록 제공 여부는 서비스에 따라 다릅니다.

번역할 텍스트는 사용자가 설정한 AI 주소로 전송됩니다. 활성 번역 패널에서 번역 대상 언어를 변경하면 추가 요청이 발생할 수 있습니다. 연결 테스트는 짧은 테스트 요청을 보내며 모델 조회도 설정한 서비스에 접속합니다. API 키는 잠금 해제 비밀번호를 이용해 AES-256-GCM으로 로컬 암호화합니다. Chrome 재시작 또는 확장 프로그램 재로드·업데이트 후에는 다시 잠금을 해제하세요. 비밀번호는 저장하거나 AI 제공업체에 전송하지 않습니다. 잠금 해제된 키는 세션 메모리에 임시 보관하며 설정에서 잠그거나 삭제할 수 있습니다. 설정은 Chrome 동기화되지 않습니다. 사용 분석이나 영구 번역 기록이 없으며 전체 웹페이지를 자동 스캔하여 업로드하지 않습니다.

모든 사이트 접근 권한은 일반 HTTP/HTTPS 페이지의 선택 번역 및 설정한 API 통신에 사용됩니다. Chrome 내부 페이지, Chrome Web Store 등 보호된 페이지에서는 페이지 내 기능이 제한될 수 있습니다. AI 번역에는 오류가 있을 수 있으므로 중요한 정보는 확인하세요. 전송된 내용에는 제공업체의 데이터 처리 정책이 적용됩니다.
