Transight AI — 언어를 넘어, 의미를 더 가까이.

내 AI 서비스로 텍스트와 붙여넣은 이미지를 번역하세요. 도구 모음, 선택 영역 끝의 번역 아이콘 또는 오른쪽 클릭 메뉴로 실행합니다.

SIMPLE / FULL 두 가지 모드
• 기본값은 Full Translate입니다. 최대 5개 모델을 동시에 사용하고 독립 결과 카드에서 비교·복사·개별 재시도할 수 있습니다.
• 설정이나 패널 상단 레이아웃 아이콘으로 Simple Translate를 선택하세요. 선택 모델 목록의 첫 모델만 사용하고 원문 편집, 번역문, 원문·대상 언어 선택을 표시합니다. 번역 버튼은 없습니다.
• Simple은 언어를 바꾸거나 입력을 약 0.6초 멈추면 다시 번역합니다. 복사와 로컬 음성 읽기도 지원합니다.
• 같은 아이콘으로 Full로 돌아갑니다. 모드는 저장되며 도구 모음 팝업은 항상 전체 레이아웃입니다.

페이지를 떠나지 않고 읽기
• 글을 선택하면 약 2.5초 동안 작은 아이콘이 나타납니다. 선택만으로 업로드하지 않고 클릭하면 번역합니다.
• 패널을 고정하고 상단을 드래그해 이동하세요. 1~2개 모델은 높이를 자동 조정하고 더 많으면 두 결과를 먼저 표시하며 나머지는 스크롤합니다(화면 공간에 따라 다름).
• 원문 언어를 자동 감지하거나 직접 선택하세요. 대상 언어는 팝업·패널·설정 간에 기억·동기화됩니다.
• Full에서 진행 중 번역을 취소하거나 실패한 모델만 다시 시도할 수 있습니다. 인증 오류 링크로 설정을 열 수 있습니다.
• 스피커를 눌러 읽고 다시 눌러 중지합니다. 자동 재생하지 않으며 설치된 로컬 음성만 사용합니다.

이미지와 맞춤 설정
• 팝업 또는 Full 원문란에 최대 5개 이미지를 붙여넣으세요. 왼쪽 위 썸네일 한 줄을 가로 스크롤하고 개별 삭제하며 아래에 텍스트를 입력합니다.
• 이미지 입력 지원 모델이 필요합니다. 붙여넣기·미리보기만으로 전송하지 않습니다. 팝업의 캡처 버튼은 제거했으므로 시스템 스크린샷을 복사해 붙여넣으세요.
• 설정에서 선택 번역을 켜거나 끌 수 있습니다. 꺼도 도구 모음과 오른쪽 클릭 번역은 사용 가능합니다.
• 시스템 프롬프트를 편집하거나 기본값으로 복원하세요. 원문, 언어, 사용 가능한 페이지 제목·description, 번역 스타일 변수를 지원합니다. 전체 페이지 수집이나 별도 AI 요약은 하지 않습니다.

시작하기
1. Chat Completions 호환 Base URL과 필요한 경우 API 키를 입력합니다.
2. 모델 목록을 가져오거나 ID를 직접 입력하고 최대 5개를 선택합니다.
3. 키 저장 시 6자 이상의 로컬 잠금 해제 비밀번호를 설정·확인합니다. 데이터 전송 안내를 읽고 저장한 뒤 연결을 테스트합니다.
4. 일반 HTTP/HTTPS 웹페이지나 팝업에서 번역하세요. 필요할 때 팝업·패널에서 바로 잠금을 해제해 진행할 수 있습니다.

표시 언어는 한국어, 日本語, English, 简体中文, 繁體中文입니다. 브라우저를 따르며 미지원 언어는 영어로 표시합니다. 팝업 또는 설정에서 바꾸면 페이지 패널도 따릅니다. 패널에는 별도 표시 언어 버튼이 없습니다. 번역 대상은 한·일·영·중국어 2종·프랑스어·독일어·스페인어·러시아어·포르투갈어입니다.

개인정보와 제한
AI 구독·키·크레딧은 포함하지 않습니다. 모델별 요청으로 서비스 비용이 발생할 수 있습니다. 원문·이미지·해당 프롬프트/페이지 정보는 설정한 제공업체에 전송됩니다. Simple 편집, 언어·모드 변경, 재시도는 새 요청을 보낼 수 있습니다. 모델 조회는 키, 연결 테스트는 예시 텍스트를 보냅니다. 취소해도 이미 전송된 데이터는 회수할 수 없습니다.

키는 AES-256-GCM 및 비밀번호 파생 키로 로컬 암호화하며 해제 후 제한된 session storage에 임시 보관합니다. 브라우저 재시작·확장 재로드/업데이트 후 다시 해제해야 합니다. 비밀번호는 저장하거나 AI로 보내지 않습니다. Chrome 동기화, 내장 분석, 영구 번역 기록, 음성 저장은 없습니다. 이미지는 메모리에만 있고 음성은 로컬 엔진만 사용합니다. 제공업체의 데이터 정책은 별도로 적용됩니다.

Chrome 내부 페이지 및 Chrome Web Store 등 보호 페이지에서는 페이지 기능이 제한됩니다. 모델 목록·이미지 입력은 제공업체에 따라 다릅니다. AI 번역은 부정확할 수 있으므로 중요한 내용은 확인하세요.
