Transight AI — 언어를 넘어, 이해를 더 가까이.

직접 설정한 AI 서비스로 선택한 글, 입력한 문장, 붙여넣은 이미지와 웹페이지를 번역합니다. 도구 모음 팝업, 선택 아이콘, 우클릭 메뉴에서 사용할 수 있습니다.

AI 페이지 내 번역
• AI 페이지 번역을 선택하고 제공업체, 첫 번째 설정 모델, 대상 언어, 개인정보 및 비용 안내를 확인한 후 시작합니다. 확인 전에는 페이지 본문을 보내지 않습니다.
• 일반적인 표시 텍스트를 제자리에서 바꾸며 요소, 링크와 이벤트를 유지합니다. 글자 수에 따라 줄바꿈과 높이는 달라질 수 있습니다.
• 중지, 원문/번역 전환, 복원 및 종료, 도구 모음 접기를 지원합니다. 허용한 세션 중 추가되거나 표시된 텍스트도 번역합니다. URL 변경 시 종료하며, 회차 한도 이후에는 계속하기 확인이 필요합니다.
• 양식, 편집기, 코드, 숨겨진 영역과 번역 금지 영역을 건너뜁니다. 다른 일반 본문에도 민감한 정보가 있을 수 있습니다. iframe 내부, Shadow DOM, PDF, 이미지/캔버스 글자는 지원하지 않습니다. 전용 구조화 프롬프트를 사용하며 사용자 지정 글 번역 프롬프트는 사용하지 않습니다.

Simple / Full 모드
• Full은 최대 5개 모델을 독립 카드로 비교하고 복사, 취소, 실패한 결과의 개별 재시도를 지원합니다.
• Simple은 첫 모델만 사용합니다. 원문을 편집할 수 있으며 입력을 잠시 멈추거나 언어를 바꾸면 자동 번역합니다. 번역 버튼은 없습니다.
• 레이아웃 아이콘 또는 설정에서 전환하며 팝업, 패널과 설정에서 모드 및 대상 언어를 기억합니다.
• 선택한 글 끝에 작은 아이콘이 나타납니다. 선택만으로 전송하지 않으며 클릭하면 번역합니다. 패널 고정 및 상단 드래그가 가능합니다.
• 두 모드 모두 복사와 읽기를 지원합니다. 모든 언어에서 설치된 로컬 중국어 음성을 사용하며 발음은 엔진에 따라 다릅니다. 자동 재생하지 않습니다.

이미지와 설정
• Full에서 최대 5장의 이미지를 붙여넣고 가로 스크롤 썸네일에서 개별 삭제할 수 있습니다. 이미지 지원 모델이 필요합니다. 미리보기만으로 업로드하지 않습니다. 시스템 캡처 도구로 캡처한 뒤 붙여넣으세요.
• 선택 번역 켜기/끄기, 표현 스타일, 모델 목록 가져오기, ID 직접 입력 및 글 번역용 시스템 프롬프트 편집을 지원합니다. 글/선택 프롬프트의 선택적 페이지 정보는 제목과 description 메타데이터이며 별도의 전체 페이지 AI 요약은 생성하지 않습니다.
• 표시 언어는 영어, 간체/번체 중국어, 일본어, 한국어입니다. 기본은 브라우저 언어이며 미지원 시 영어를 사용합니다. 대상 언어는 10개입니다.

별도의 Google 번역
• Google 페이지 번역은 원래 HTTP/HTTPS URL과 대상 언어를 새 Google 탭에 전달합니다. 원본 페이지는 바뀌지 않습니다. 로그인 전용 페이지나 인트라넷은 작동하지 않을 수 있습니다.
• Google 무료 글 번역은 최대 5,000자와 언어를 새 탭에 전달하며 설정에서 끌 수 있습니다. 두 기능 모두 AI 키가 필요 없고 결과는 Google에 표시됩니다.
• 클릭할 때만 전송하며 AI 인증정보나 이미지는 보내지 않습니다. 글이나 URL이 브라우저 기록에 남을 수 있으므로 민감한 정보를 피하세요. Google 정책과 서비스 제공 상태가 적용됩니다.

설정과 개인정보
Chat Completions 호환 Base URL, 필요한 API 키, 모델 ID를 입력하세요. 키 저장에는 최소 6자 로컬 잠금 해제 비밀번호가 필요합니다. PBKDF2 파생 키와 AES-256-GCM으로 암호화하며 해제된 키는 제한된 세션 저장소에만 유지합니다. 팝업/패널에서 해제할 수 있고 비밀번호는 AI로 보내지 않습니다.

AI 요청은 제출한 글, 이미지와 해당 프롬프트 정보를 설정한 엔드포인트로 보냅니다. AI 페이지 번역을 명시적으로 확인한 후에는 일반 본문과 세션 중 새로 표시된 글을 묶음으로 전송합니다. 이 페이지 요청에는 전체 HTML/DOM, URL 또는 쿠키가 포함되지 않습니다. 페이지 원문과 번역은 메모리에만 유지하며 영구 기록으로 저장하지 않습니다. API 인증, 모델 검색 및 연결 테스트도 설정한 제공업체에 접속합니다. 여러 모델과 자동 재번역으로 비용이 늘 수 있습니다. 서비스, 키, 크레딧은 포함되지 않으며 내장 분석이나 영구 번역 기록은 없습니다. 보호된 브라우저 페이지에는 패널을 표시할 수 없습니다.
