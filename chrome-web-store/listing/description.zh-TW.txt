譯見 AI — 讓理解，少一點距離。 · v0.1.3

使用自己的 AI 服務翻譯文字與貼上圖片。可從工具列開啟、點擊網頁選取文字尾端的翻譯圖示，或使用右鍵翻譯。

精簡與完整，兩種模式
• 預設 Full Translate：最多選擇 5 個模型並行翻譯，獨立結果卡片，可逐一複製或重試失敗結果。
• 在設定啟用 Simple Translate，或點擊浮窗頂部的版面圖示切換。精簡模式只使用模型清單第一項，顯示可編輯原文、譯文、來源/目標語言選擇，不顯示翻譯按鈕。
• 精簡模式切換語言或停止輸入約 0.6 秒後自動翻譯，仍保留複製和本機語音朗讀。
• 圖示支援雙向切換並立即儲存模式；工具列彈出視窗始終保留完整版面。

不中斷閱讀
• 選取文字後，尾端附近出現小圖示，約 2.5 秒自動消失；僅選取不傳送內容，點擊後才開啟翻譯。
• 可固定本次浮窗並拖曳頂部。1–2 個模型自適應高度，更多模型先顯示兩個，其餘捲動查看，受可用螢幕空間限制。
• 來源語言可自動偵測或手動選擇；目標語言在彈出視窗、浮窗、設定間記憶與同步。
• 完整模式可取消翻譯，失敗模型可獨立重試；認證錯誤提供前往設定的連結。
• 點擊揚聲器朗讀，再次點擊停止，不自動播放。所有目標語言統一使用本機中文語音，不改寫譯文；需系統安裝中文語音，外語發音依引擎支援而定。

圖片與個人偏好
• 在彈出視窗或完整模式原文框貼上剪貼簿圖片，最多 5 張。縮圖位於左上方單行顯示，可水平捲動，文字在下方輸入，圖片可獨立刪除。
• 需要模型支援圖片輸入。貼上與預覽不會上傳。彈出視窗已移除截圖入口，請以系統截圖工具複製圖片後貼上。
• 設定可啟用/停用選取翻譯圖示；停用後工具列及主動右鍵翻譯仍可使用。
• 可自訂系統提示詞、還原預設，支援原文、來源/目標語言、可用網頁標題/description 摘要和翻譯風格變數。不擷取整頁，也不額外呼叫 AI 產生摘要。

開始使用
1. 填寫相容 Chat Completions 的 Base URL，服務需要時填寫 API Key。
2. 取得模型清單或手動輸入 ID，最多選擇 5 個模型。
3. 儲存 Key 時設定並確認至少 6 個字元的本機解鎖密碼，閱讀資料傳送提示，儲存並測試連線。
4. 在工具列或一般 HTTP/HTTPS 網頁翻譯。需要時可直接在彈出視窗/浮窗解鎖，繼續等待中的翻譯。

介面支援繁體中文、简体中文、English、日本語、한국어；預設跟隨瀏覽器，未匹配時使用英文。在彈出視窗或設定切換顯示語言；浮窗跟隨偏好，不顯示獨立語言按鈕。目標語言包含簡繁中文、英、日、韓、法、德、西、俄、葡共十種。

隱私與限制
不提供 AI 訂閱、Key 或額度。每個模型分別請求，服務商可能收費。翻譯時向你設定的服務傳送原文、圖片及適用的提示詞/網頁中繼資料；精簡模式編輯、切換語言/模式、重試可能發起新請求。取得模型可能傳送 Key，連線測試傳送範例文字。取消無法撤回服務端已收到的資料。

Key 使用 AES-256-GCM 和密碼衍生金鑰在本機加密；解鎖後僅暫存在受限 session storage。重新啟動瀏覽器、重新載入或更新擴充功能後須解鎖。密碼不儲存、不傳給 AI。沒有 Chrome 同步、內建分析統計、持久翻譯紀錄或音訊儲存。圖片僅保留於記憶體，朗讀僅使用標示為本機的語音。第三方服務仍適用其資料政策。

Chrome 內部頁、Chrome Web Store 等受保護頁面可能限制浮窗。模型清單及圖片能力依提供者而定。AI 翻譯可能有誤，請核對重要資訊。
