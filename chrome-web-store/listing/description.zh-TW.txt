譯見 AI（Transight AI）——讓理解，少一點距離。

使用你自己的 AI 服務和模型，在閱讀時隨手翻譯。支援工具列輸入、網頁選取文字和右鍵翻譯，無需離開目前頁面，即可閱讀並對照多個模型的譯文。

你的服務，你的模型
• 設定相容 Chat Completions API 的服務網址、API Key 和模型 ID。
• 服務商支援時可取得模型清單，也可手動填寫模型 ID。
• 最多同時選擇 5 個模型，分別顯示獨立譯文卡片。
• 每個結果可單獨複製，失敗後可單獨重試。

不中斷閱讀的翻譯體驗
• 支援手動輸入、貼上文字和選取文字翻譯。
• 選取文字與右鍵翻譯共用同一個網頁浮動視窗。
• 可固定本次浮動視窗，透過頂部區域拖曳位置。
• 1–2 個模型時高度隨內容自動調整；3 個及以上模型時顯示前兩張結果卡片，其餘捲動查看，小螢幕下以可用空間為限。
• 提供自然流暢、忠實原文和專業嚴謹三種翻譯風格。

語言支援
• 目標語言支援簡體中文、繁體中文、英語、日語、韓語、法語、德語、西班牙語、俄語和葡萄牙語。
• 介面支援簡體中文、繁體中文與英文，預設跟隨瀏覽器語言，未匹配時使用英文，也可手動切換。
• 台灣、香港、澳門及 Hant 瀏覽器語言使用繁體中文；切換顯示語言不會變更翻譯的目標語言。

如何使用
1. 開啟設定，填寫相容 AI 服務的 API 網址，以及服務所需的 API Key。
2. 取得模型清單或手動填寫模型 ID，選擇希望使用的模型。
3. 閱讀資料傳送提示，儲存設定並測試連線。
4. 在一般網頁中選取文字後點擊翻譯圖示，或使用右鍵翻譯；也可以從工具列彈出視窗貼上文字翻譯。

使用前請了解
擴充功能不附帶 AI 訂閱、API Key 或翻譯額度，需要自行準備相容的 AI 服務。服務商可能收取費用；每個選中的模型會分別傳送一次請求。也支援不需要驗證的本機服務。能否取得模型清單取決於服務商。

待翻譯文字會傳送到你設定的 AI API。在已開啟的翻譯介面中切換目標語言可能重新傳送翻譯請求；測試連線會傳送短測試請求，取得模型清單也會存取已設定的服務。API Key 和設定儲存在目前瀏覽器本機，不透過 Chrome 同步；本機儲存並非加密保險箱。擴充功能不包含統計追蹤，不儲存持久翻譯紀錄，也不會自動掃描並上傳整篇網頁。

所有網站存取權限用於在一般 HTTP/HTTPS 網頁提供選取文字翻譯，並存取你設定的 AI API。Chrome 內部頁面、Chrome Web Store 等受保護頁面可能限制網頁浮動視窗功能。AI 譯文可能不準確，請自行核實重要內容；提交文字適用所選服務商的資料處理政策。
