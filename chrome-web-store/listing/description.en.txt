Transight AI — Across languages. Closer in meaning.

Translate selected text, typed text, pasted images, or an entire webpage using your own AI service. Open the toolbar popup, click the icon beside a selection, or use the right-click translation command.

AI WEBPAGE TRANSLATION — STAY ON THE PAGE
• Choose AI webpage translation in the popup or a selection/right-click panel. Review the provider, first configured model, target language, privacy notice and possible costs, then confirm before page text is sent.
• Ordinary rendered text is translated in place. Page elements, links and event handlers are retained; translated text can change line wrapping and element heights.
• Stop, compare original/translation, restore and end the session, or collapse the toolbar. Newly revealed or added text is processed during the authorized session. A URL change ends the session; continuing after a round limit needs confirmation.
• Forms, editors, code, hidden text and no-translate regions are skipped. Other page text can still contain sensitive information. Iframe content, Shadow DOM, PDFs and image/canvas text are not supported. Uses a dedicated structured prompt rather than the custom text-translation prompt.

SIMPLE OR FULL
• Full mode compares up to 5 models in separate cards. Copy, cancel, or retry failed results independently.
• Simple mode uses only the first model, with editable source text and source/target selectors. It translates automatically after a short typing pause or language change, without a Translate button.
• Switch modes from the layout icon or Settings. Mode and target language preferences stay synchronized across popup, panels and Settings.
• Select text to show a compact icon near its end. Selection alone sends nothing. Click to translate, pin the panel, or drag its top bar.
• Copy and speech controls are available in both modes. Speech uses an installed local Chinese voice for all languages; pronunciation quality varies. No automatic playback.

IMAGES AND SETTINGS
• Paste up to 5 clipboard images in Full mode; thumbnails scroll horizontally and can be removed individually. Requires a model that accepts images. Previewing alone does not upload images. Use a system screenshot tool, then paste.
• Enable/disable automatic selection controls, choose translation style, fetch a model list or enter model IDs, and customize the text-translation system prompt. Optional page context for text/selection prompts uses available title/description metadata, not an AI-generated whole-page summary.
• Five interface languages: English, Simplified Chinese, Traditional Chinese, Japanese and Korean. Browser language is followed by default with English fallback. Ten target languages are supported.

SEPARATE GOOGLE SHORTCUTS
• Google whole-page translation opens the original HTTP/HTTPS page URL with the current target language in a new Google tab. It does not modify the original page; private or login-only sites may not work.
• Google free text translation opens up to 5,000 source characters with the chosen languages in a new tab. It can be disabled in Settings. Neither entry requires an AI key. Results stay on Google.
• Only clicking sends text or a URL to Google. No AI credentials or images are included. URLs/text may appear in browser history; Google policies and availability apply.

SETUP AND PRIVACY
Enter a Chat Completions-compatible Base URL, API key if needed, and model IDs. To persist a key, create a local unlock password of at least 6 characters. Keys are encrypted locally using AES-256-GCM with a PBKDF2-derived key; unlocked keys are held in restricted session storage. Unlock inside the popup/panel when needed. Passwords are not sent to AI providers.

AI requests send submitted text, images and applicable prompt metadata to your configured endpoint. After explicit AI webpage confirmation, ordinary page text, including newly revealed content, is sent in batches; whole HTML/DOM, page URL and cookies are not included in those requests. Original/translated page text remains in memory, not persistent history. API authentication is sent to the configured provider. Model discovery and connection testing also contact that provider. Multiple models and automatic retranslation can increase usage costs. No service, key, credits or subscription is included; there is no built-in analytics or persistent translation history. Protected browser pages cannot host on-page controls.
