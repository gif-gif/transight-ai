Transight AI — 言語を越えて、意味をもっと身近に。

自分の AI サービスとモデルを使って、読んでいる文章をその場で翻訳。ツールバーから開く、選択範囲の翻訳アイコンをクリックする、右クリックメニューを使う。この 3 つの方法で、ページを離れずに訳文を読んで比較できます。

使うモデルは、あなたが選ぶ
• ベース URL、API キー、モデル ID を設定して、Chat Completions 互換サービスに接続します。
• 対応サービスではモデル一覧を取得できます。ID の手入力も可能です。
• 最大 5 モデルを選択し、独立したカードで訳文を比較できます。
• 各カードでコピー、失敗したモデルだけの再試行ができます。

読書の流れを止めない
• 入力、貼り付け、選択した文章を翻訳します。
• 選択翻訳と右クリック翻訳は共通のページ内パネルを使用します。
• 今回のパネルを固定し、上部をドラッグして移動できます。
• 1〜2 モデルでは内容に応じて高さを調整。3 モデル以上では最初の 2 件を表示し、残りをスクロールします。画面の空き領域による制限があります。
• 自然な表現、原文に忠実、専門的で正確な翻訳スタイルを選べます。

ページを離れずにロック解除
• 保存する API キーをローカルのパスワードで保護します。
• ツールバーのポップアップやページ内パネルのコンパクトなフォームで解除できます。解除後に待機中の翻訳を続行します。
• 設定からすぐにロックしたり、保存キーを削除したりできます。忘れたパスワードは復元できません。キーを削除して入力し直してください。

対応言語
• 翻訳先：中国語（簡体字・繁体字）、英語、日本語、韓国語、フランス語、ドイツ語、スペイン語、ロシア語、ポルトガル語。
• UI：中国語（簡体字・繁体字）、英語、日本語、韓国語。ブラウザーの言語に合わせ、未対応の場合は英語を使用します。手動切り替えも可能です。

使い始めるには
1. 設定を開き、対応する AI サービスのベース URL と、必要な場合は API キーを入力します。
2. モデル一覧を取得するか ID を入力し、使用するモデルを選択します。
3. API キーを保存する場合は 6 文字以上のローカル解除パスワードを設定・確認します。データ送信の案内を確認し、設定を保存して接続をテストします。
4. 通常のウェブページで文章を選択して翻訳アイコンをクリックするか、右クリック翻訳、ツールバーへの貼り付けを利用します。

重要な情報
Transight AI に AI サービスの契約、API キー、翻訳クレジットは付属しません。互換性のあるサービスを利用できることが必要です。サービス側で料金が発生する場合があり、選択したモデルごとに個別のリクエストを送信します。認証不要のローカルサービスにも対応します。モデル一覧の取得可否はサービスによって異なります。

翻訳する文章は、設定した AI 接続先に送信されます。翻訳中のパネルで翻訳先言語を変更すると、追加のリクエストが送信されることがあります。接続テストでは短いテスト文を送り、モデル取得でも設定したサービスと通信します。API キーは解除パスワードを使い AES-256-GCM でローカルに暗号化します。Chrome の再起動や拡張機能の再読み込み・更新後は再度解除してください。パスワードは保存せず、AI サービスにも送信しません。解除済みキーはセッション内で一時保持され、設定からロックまたは削除できます。設定は Chrome 同期されません。アクセス解析や永続的な翻訳履歴はなく、ページ全体を自動スキャンしてアップロードすることもありません。

全サイトへのアクセス権限は、通常の HTTP/HTTPS ページでの選択翻訳と設定した API への通信に使用します。Chrome 内部ページ、Chrome Web Store などの保護されたページでは機能が制限される場合があります。AI の訳文は誤ることがあるため、重要な情報は確認してください。送信内容にはサービス提供者のデータ処理ポリシーが適用されます。
