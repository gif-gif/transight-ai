Transight AI — 言葉を越えて、理解を近くに。 · v0.1.2

自分の AI サービスで文章や貼り付け画像を翻訳できます。ツールバー、選択範囲末尾付近の翻訳アイコン、右クリックから利用します。

SIMPLE / FULL の2つのモード
• 既定は Full Translate。最大5モデルを同時に使い、独立した結果カードで比較・コピー・再試行できます。
• 設定かパネル上部のレイアウトアイコンで Simple Translate に切り替えます。選択モデルの先頭だけを使い、編集可能な原文、訳文、原文・翻訳先の言語選択を表示します。翻訳ボタンはありません。
• Simple は言語変更や約0.6秒の入力停止で再翻訳します。コピーとローカル音声読み上げも使えます。
• 同じアイコンで Full に戻せます。モードは保存され、ツールバーポップアップは常に完整版面です。

ページを離れず読む
• 文字選択で小さいアイコンを約2.5秒表示します。選択だけでは送信せず、クリックで翻訳します。
• パネルを固定し、上部をドラッグして移動できます。1〜2モデルは高さを自動調整、3モデル以上は2件分を表示して残りをスクロールします（画面サイズによります）。
• 原文言語を自動検出または手動選択できます。翻訳先は各画面で記憶・同期します。
• Full は実行中の翻訳をキャンセル可能。失敗したモデルだけ再試行できます。認証エラーから設定へ移動できます。
• スピーカーを押して読み上げ、再度押すと停止します。自動再生せず、すべての対象言語でローカルの中国語音声を使用し、訳文は変更しません。中国語音声のインストールが必要で、外国語の発音はエンジンに依存します。

画像とカスタマイズ
• ポップアップまたは Full の原文欄に最大5枚の画像を貼り付けます。左上の横スクロール可能なサムネイル行から個別削除でき、その下に文章を入力できます。
• 画像入力対応モデルが必要です。貼り付け・プレビューだけでは送信しません。ポップアップのキャプチャ入口は削除済みのため、OS のスクリーンショットをコピーして貼り付けてください。
• 設定で選択翻訳をオン/オフにできます。オフでもツールバーと右クリックは利用できます。
• システムプロンプトを編集・初期化できます。原文、言語、利用可能なページタイトル・description、翻訳スタイルの変数に対応します。ページ全文の収集や別の AI 要約はしません。

使い始める
1. Chat Completions 互換サービスの Base URL と、必要に応じ API キーを入力します。
2. モデル一覧を取得するか ID を入力し、最大5モデルを選びます。
3. キー保存時は6文字以上のローカル解除パスワードを設定・確認します。データ送信の説明を確認して保存し、接続をテストします。
4. 通常の HTTP/HTTPS ページやポップアップで翻訳します。必要な場合、その場で解除して処理を再開できます。

表示言語は日本語、한국어、English、简体中文、繁體中文。ブラウザーに従い、未対応言語は英語に戻ります。表示言語はポップアップか設定で変更し、ページ内パネルはその設定に従います。翻訳先は日・韓・英・中国語2種・仏・独・西・露・葡の10種類です。

プライバシーと制限
AI 契約・キー・利用枠は付属しません。モデルごとに送信し、料金が発生する場合があります。文章・画像・該当するプロンプト/ページ情報は設定した提供元へ送られます。Simple の編集、言語・モード変更、再試行も新しい送信を行う場合があります。モデル取得ではキー、接続テストではサンプル文章を送信します。キャンセルしても送信済みデータは取り消せません。

キーは AES-256-GCM とパスワード由来の鍵でローカル暗号化し、解除後は制限付き session storage に一時保持します。再起動・拡張の再読み込み/更新後は再解除が必要です。パスワードは保存・AI送信しません。Chrome 同期、組み込み分析、永続翻訳履歴、音声保存はありません。画像はメモリ内のみで、読み上げはローカル音声のみです。提供元のデータ方針は別途適用されます。

Chrome 内部ページや Chrome Web Store などではページ内機能が制限されます。モデル一覧・画像入力は提供元次第です。AI の誤訳に注意し、重要な内容を確認してください。
