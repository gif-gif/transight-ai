# Distribution / 分发填写指南

核对日期：2026-10-06。以下为全球化插件的建议配置，**没有代你修改后台或发布**；开发者应在提交前确认服务范围。

| 字段 | 建议填写 | 说明 |
| --- | --- | --- |
| Visibility / 可见范围 | **Public / 公开** | 面向公众正式上架。与 GitHub 仓库是否公开、使用 Apache-2.0 没有自动联动 |
| Geographic distribution / 发布地区 | **All regions / 所有地区**，由你最终确认 | 符合全球化定位；若运营、服务商可用性或地区要求有限制，应取消相应地区，不承诺任何 AI 服务全球可用 |
| Trusted testers / 测试者 | 正式 Public 上架无需为分发而设置 | 仅在改用 Private 测试时配置指定 Google 账号/组；不是 AI 服务的登录账号 |
| Domain distribution / 域内分发 | 不启用 | 当前目标不是某个企业 Workspace 内部发布 |

## 如需先小范围测试

- **Unlisted / 不公开列出**：不在公开目录展示，但持有商店链接的人仍可安装；不是保密或访问控制。
- **Private / 私有**：限指定测试者等获授权人员安装。
- 三种可见范围都不能绕过商店审核。不要为了规避审核而选择 Unlisted。
- 界面现支持简体中文、繁体中文、英文、日语和韩语。发布地区、商店主要语言与显示语言是不同设置；选择 English 不会把安装范围限制为英语地区。

## 提交前确认

- [ ] 正式版选择 Public，或明确此次只是测试分发。
- [ ] 接受 All regions，或已选择允许发布的地区。
- [ ] 商品详情已说明第三方 AI 服务可能收费，未将“Apache-2.0 开源”误写成“翻译永久免费且提供无限额度”。
- [ ] 若后台另有发布时机选项，确认是审核后自动发布还是手动发布；本文件不默认替你选择。
